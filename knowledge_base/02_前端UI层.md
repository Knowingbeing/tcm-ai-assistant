## 3. 数据读写函数

### 3.1 `load_records()` — 读取问诊记录

```python
@st.cache_data(ttl=30)
def load_records():
    """
    读取问诊记录，优先 Supabase，降级 JSON 文件。
    ttl=30 秒缓存，避免频繁查询数据库。
    """
    if supabase_client.is_configured():
        records = supabase_client.get_records()
        if records is not None:
            return records
    # JSON 兜底
    if os.path.exists(JSON_FILE):
        with open(JSON_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    return []
```

**关键点**：
- `@st.cache_data(ttl=30)` — 30 秒 TTL 缓存，减少 Supabase 查询
- 保存记录后必须调用 `load_records.clear()` 失效缓存
- Supabase 返回 `None`（连接失败）时自动降级到 JSON

### 3.2 `_sb_save_record(record)` — 保存单条记录

```python
def _sb_save_record(record):
    """
    包装 supabase_client.save_record()，返回 tuple[bool, str]。
    bool: 是否保存成功
    str: 成功返回空字符串，失败返回中文错误提示
    """
    ok, msg = supabase_client.save_record(record)
    if ok:
        load_records.clear()  # 失效缓存
        return True, ""
    return False, msg
```

### 3.3 `save_records(records)` — 批量保存

```python
def save_records(records):
    """批量保存，逐条调用 _sb_save_record()"""
    if supabase_client.is_configured():
        for r in records:
            ok, msg = _sb_save_record(r)
            if not ok:
                # Supabase 失败 → 降级 JSON
                _save_to_json(records)
                return False, msg
        return True, ""
    else:
        _save_to_json(records)
        return True, ""
```

### 3.4 `_collect_symptoms_from_ten_asks(sess)` — 症状收集

```python
def _collect_symptoms_from_ten_asks(sess):
    """
    从十问歌表单数据中提取症状描述，合并到 symptoms 列表。
    
    数据源：
    1. sess["ten_asks_data"] — 十问歌 10 维度 + 经期 + 舌诊 + 脉诊
    2. sess["symptoms"] — 用户手动选择的症状标签
    
    返回：去重后的症状字符串列表
    """
    collected = list(sess.get("symptoms", []))
    ten_asks_data = sess.get("ten_asks_data", {})  # ← 已修复的 key 名
    
    for ask_key, ask_value in ten_asks_data.items():
        if ask_value and ask_value != "无异常" and ask_value != "未填写":
            # 将十问歌的选项值转化为症状描述
            collected.append(f"{ask_key}: {ask_value}")
    
    # 去重
    return list(dict.fromkeys(collected))
```

**Bug 修复记录**：原代码使用 `sess.get("ten_asks", {})`，但十问歌数据实际存储在 `sess["ten_asks_data"]` 中，导致十问歌采集的症状信息全部丢失。修正后所有维度的症状均可正确传递给 AI 引擎。

**多轮追问渲染逻辑**：
1. `should_ask_followup()` 返回 `need_followup=True` 时，将 `questions` 存入 `sess["pending_questions"]`
2. UI 遍历 `pending_questions`，每个问题渲染为 `st.radio` 组件
3. 用户选择后调用 `_apply_followup_answer()` 写回 session_state
4. `sess["round"] += 1`，若 round < 2 且仍需追问，继续渲染下一轮
