# 项目总览

> 文档版本：2026-06-25 | 对应代码版本：v2.x（P1 Session 多轮问诊）

## 1. 项目定位

中医AI智能问诊助手是一个基于 Streamlit 构建的 Web 应用，核心功能是通过大语言模型（LLM）辅助中医辨证施治。用户输入主诉、症状、舌象、脉象等信息后，系统调用 AI 引擎进行辨证分析，输出证型、治法、方剂推荐及置信度。同时内置十问歌结构化表单和多轮追问机制，模拟真实中医问诊流程。

| 部署 | Docker / Streamlit Cloud | - | Dockerfile + streamlit_app.py 入口 |

## 5. 核心设计决策

1. **双存储后端**：Supabase 优先 + JSON 本地兜底，通过 `is_configured()` 在运行时自动切换，确保无网络/未配置时仍可用。
2. **统一 LLM 接口**：使用 OpenAI Python SDK 的 `base_url` 参数统一接入 7 家厂商，避免多 SDK 依赖。
3. **规则引擎兜底**：当 API Key 未配置或调用失败时，`_rule_based_diagnosis()` 提供 20+ 证型的关键词匹配，保证基本可用性。
4. **十问歌结构化**：v2.0 引入 `data/ten_asks.py`，将传统中医十问歌编码为结构化表单数据，提升问诊信息采集完整性。
5. **错误透传机制**：`save_record` 返回 `tuple[bool, str]`，所有存储错误翻译为中文排查建议，直接展示给用户。
6. **单租户无 RLS**：Supabase schema 显式禁用 RLS，适合个人/家庭使用场景，简化配置。
